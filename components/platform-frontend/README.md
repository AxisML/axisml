# platform-frontend

Frontend for AxisML Platform — the Web UI delivered to users. A React + Vite +
TypeScript single-page app that faithfully implements the product prototype in
[`docs/product_design/prototype/`](../../docs/product_design/prototype) and talks
to the platform-backend through a **typed client generated from the OpenAPI spec**.

## Tech stack

- **Language**: TypeScript
- **Framework / build**: React 19 + Vite 6 (SPA; production bundle to `dist/`)
- **Routing**: react-router-dom (routes map 1:1 to the prototype pages)
- **Data**: `@tanstack/react-query` over the generated fetch client; query cache + polling
- **API client**: generated by `@hey-api/openapi-ts` from
  [`docs/openapi/platform.yaml`](../../docs/openapi/platform.yaml) into
  [`src/api/generated/`](src/api/generated) — **never hand-edited**
- **Design system**: the prototype's own token-based CSS (`src/styles/app.css`),
  ported verbatim so the UI matches the prototype exactly

## Layout

```
index.html              Vite entry HTML (mounts the React app)
openapi-ts.config.ts    API client generation config (→ src/api/generated)
src/
  ├── main.tsx          App bootstrap (QueryClient + Router + providers)
  ├── api/
  │   ├── client.ts     Runtime config for the generated fetch client (cookie + JWT auth)
  │   ├── generated/    GENERATED client + types (do not edit; run `make gen-api`)
  │   └── hooks/        react-query wrappers over the generated SDK
  ├── app/              Store (role/tenant/theme/lang), UI services (toast/confirm), router
  ├── shell/            App shell — Sidebar + Topbar (ported from the prototype shell)
  ├── components/       Shared UI (Icon, Drawer, Tabs, Segmented, RunBar, form widgets)
  ├── pages/            One component per prototype page
  └── styles/app.css    Design system (ported from the prototype)
CONVENTIONS.md          Page-authoring rules (prototype → JSX)
```

## API client generation

The typed client is the single source of truth for HTTP types and is regenerated
from the OpenAPI contract — never written by hand:

```sh
make gen-api        # or: pnpm gen:api
```

Regenerate whenever [`docs/openapi/platform.yaml`](../../docs/openapi/platform.yaml)
changes. Auth is cookie + JWT only; the frontend does not derive or send tenant
scope (the topbar "所属租户" switcher is a client-side display scope).

## Local development

Dependencies are managed with **pnpm** (`packageManager` is pinned in `package.json`).

```sh
make help            # list all targets
make install         # pnpm install
make dev             # start the dev server (proxies /api → $VITE_API_TARGET, default :8080)
make / make build    # type-check + build the production bundle into dist/
make test            # unit tests
make lint            # lint the codebase
make image           # docker build -> ghcr.io/axisml/axisml-platform-frontend:0.1.0
make clean           # remove dist/, build/, and the local build cache
```

`IMAGE_TAG` defaults to `0.1.0` and must track the `appVersion` in
[`deploy/helm/axisml-system/Chart.yaml`](../../deploy/helm/axisml-system/Chart.yaml).

## Deployment

Platform frontend ships as part of the `axisml-platform` chart
(`deploy/helm/axisml-platform/`). In production it is fronted by the Envoy Gateway.
