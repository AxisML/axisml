# AxisML Platform 线框图（Wireframe）

本文件汇总 Platform 各功能页面的纯 ASCII mockup，供前端开发与产品对齐视觉骨架使用。字段语义、写入位置、过滤规则、RBAC 矩阵以 [platform.md](platform.md) 各功能章节为准；本文不重复表格列说明，仅给出版面占位。

线框图按「一级菜单 → 二级页面」组织，命名与 [platform.md §1 概述](platform.md#1-概述) 的菜单矩阵一致。

主区：列表 / 详情 / 表单三态切换。

## 2. 租户管理

### 2.1 详情页 · 配额 Tab

参见 [platform.md §6.4 详情页 Tab](platform.md#64-详情页-tab)（Tab 2 配额）。

```
[default 池]                                        [+ 新增配额]
┌──────────┬──────────────────┬──────────────────┬───────┬─────┐
│ 配额名    │ min              │ max              │ used  │ 操作 │
├──────────┼──────────────────┼──────────────────┼───────┼─────┤
│ default  │ cpu=20           │ cpu=100          │ cpu=8 │ ✏️ ❌│
│ training │ cpu=10, gpu=2    │ cpu=50,  gpu=8   │ ...   │ ✏️ ❌│
└──────────┴──────────────────┴──────────────────┴───────┴─────┘
合计 max（仅展示）：cpu=150, gpu=8
```

要点：
- 顶部 `[default 池]` 为「资源池切换」标签；多池时多组重复版面。
- 「合计 max」是肉眼参考，不做硬阻断（决策见 [platform.md §12 关键设计决策](platform.md#12-关键设计决策)）。

## 3. 资源池与资源单元

### 3.1 详情页 · 资源单元 Tab

参见 [platform.md §7.4 详情页 Tab](platform.md#74-详情页-tab)（Tab 2 资源单元）。

```
[+ 新建资源单元]
┌──────────────────┬──────────────────────────┬──────────────────────┬────────────────────────┬─────┐
│ 名称              │ requests                 │ limits               │ node_selector          │ 操作 │
├──────────────────┼──────────────────────────┼──────────────────────┼────────────────────────┼─────┤
│ a100-1x-large    │ cpu=8, mem=64Gi, gpu=1   │ cpu=8, mem=64Gi      │ nvidia.com/gpu.product │ ✏️ ❌│
│                  │                          │                      │ =A100-SXM4-80GB        │     │
│ cpu-medium       │ cpu=4, mem=16Gi          │ cpu=4, mem=16Gi      │ —                      │ ✏️ ❌│
└──────────────────┴──────────────────────────┴──────────────────────┴────────────────────────┴─────┘
```

要点：
- 行可展开，展开后展示 `pool.node_selector` ⊕ `unit.node_selector` 合并预览（Pool 优先）。
- 删除前置阻断信息（使用此 unit 的活跃 Job / Service 数）在二次确认弹窗呈现，本图未画。
