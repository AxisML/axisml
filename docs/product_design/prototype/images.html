引用外部仓库中的已有镜像，平台将其同步到镜像仓，适合从 Docker Hub、NGC、Harbor 等公开或私有仓库导入。

使用 Docker 将本地构建好的镜像直接推送到镜像仓，适合自建镜像与 CI 流水线。

1 · 登录镜像仓
# 临时凭证有效期 1h
docker login zot.axisml.internal -u <用户名> -p <token>
2 · 打标签并推送
# 1. 为本地镜像打上目标 tag
docker tag <本地镜像>:<tag> zot.axisml.internal/llm-lab/pytorch:2.4-cu124

# 2. 推送到镜像仓
docker push zot.axisml.internal/llm-lab/pytorch:2.4-cu124
