# Security Policy

## Supported Versions

AxisML is in early development; security fixes are applied to the `main` branch
only. There is no long-term-support release line yet.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Instead, use one of the following private channels:

- Open a private advisory via GitHub:
  [Report a vulnerability](https://github.com/AxisML/axisml/security/advisories/new)
  (Security → Advisories → *Report a vulnerability*).
- Or email **zhenlohuang@gmail.com** with the details.

Please include:

- The affected component (e.g. `tenant-operator`, `compute-service`, a Helm
  chart).
- A description of the vulnerability and its impact.
- Steps to reproduce or a proof of concept.
- Affected version / commit, and your environment (Kubernetes version, etc.).

## What to Expect

- We aim to acknowledge your report within **5 business days**.
- We will keep you informed as we investigate and work on a fix.
- Please give us a reasonable window to release a fix before any public
  disclosure. We will credit reporters who wish to be acknowledged.

Thank you for helping keep AxisML and its users safe.
